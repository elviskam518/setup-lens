# Atlas demo fixture

These files demonstrate a mixed Node.js, Python, Rust and Docker repository.
This is **not a runnable application**. Some commands are deliberately review-worthy;
the bootstrap URL uses the reserved `.invalid` domain. Do not execute the recipes.

From the SetupLens repository root:

```sh
python -m setuplens examples/atlas-demo --format html -o atlas-report.html
```

Only the SetupLens command above is meant to run.
